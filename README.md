# QuickChat - PROG5121 POE (Part 1)
An interactive Java console application that includes user registration, input validation, and login authentication.

## Features Implemented
* **Username Validation:** Ensures an underscore is included and total length is ≤ 5 characters.
* **Password Complexity:** Validates length (≥ 8), uppercase letters, numbers, and special characters.
* **Cell Phone Match:** Tracks South African international numbers (`+27`).
* **Unit Testing:** Backed by automated JUnit test assertions.

## Architecture Planning & Framework Design
The architecture and workflows were planned by analyzing standard messaging layouts and client-server communication channels. 
It uses system scanners and expression helper engines matching usual platform specifications.
## Features & Boundary Rules
The variable requirements, required class structures, and boundary parameters like the South African `+27` phone were implemented following the assignment brief [3] and the instructional adjustments in the module support tutorial.
