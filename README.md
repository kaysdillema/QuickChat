# QuickChat - PROG5121 POE (Part 2)
An interactive Java console application that includes secure user account registration, credential input validation, login authentication, and messaging transaction features.

## Features Implemented
* **Username Validation:** Ensures an underscore is included and total length is ≤ 5 characters.
* **Password Complexity:** Validates length (≥ 8), uppercase letters, numbers, and special characters.
* **Cell Phone Match:** Tracks South African international numbers (`+27`).
* **Message Hash Generation:** Autogenerates an identification string combining message metrics, loop cycles, and uppercase delimiters [5].
* **Length Constraints:** Validates text payloads to ensures messages do not exceed 250 characters [5].
* **CI/CD Automation:** Integrated with active GitHub Actions pipelines to automatically execute test builds when file shifts [1].
* **Unit Testing:** Backed by automated JUnit 4 test assertions verifying both credential checks and messaging models [3].

## Architecture Planning & Framework Design
The core architecture and transactional workflows of this messaging client were planned by analyzing standard chat configurations and remote client-server layout matrices [6]. The application uses foundational system scanners and regular expression matching objects compliant with standard platform specifications [5]. For local transaction caching, payload properties are parsed, structured, and saved externally leveraging a lightweight data token serialization engine [7]. Version control logs were recorded through a visual repository deployment pipeline [2], while code modifications were continually checked by an external cloud automation runner framework [1].

## Features & Boundary Rules
The variable parameters, required class structures, and input boundaries (including the character length checks for usernames and the strict South African phone rules) were structured to conform with the official assignment requirements [3] and the implementation guidelines demonstrated in the institutional support session [4].
